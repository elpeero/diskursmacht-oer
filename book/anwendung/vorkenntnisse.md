# 📘 Anwendung der OER

<!-- ## Die verschiedenen Arten dieses Buch zu lesen -->

Diese OER ist so angelegt, dass sie möglichst vielfältig eingesetzt werden kann. In Anlehnung an das Konzept der QUADRIGA Open Educational Resources {cite:p}`Schnaitter.2025` werden Kapitel nach ihrer intendierten Verwendungsweise markiert. Diese Teilen sich in drei Arten von intendierter Verwendung:


1. 📘 Lesemodus: Sie lesen die OER in einem Browser (getestet mit Firefox) wie eine gewöhnliche Webseite. In diesem Modus sind keine Programmierkenntnisse oder Erfahrung mit Jupyter Notebooks nötig.
2. 🚀 Reproduktionsmodus: In Kapiteln, die mit einem Raketensymbol gekennzeichnet sind, finden Sie ausführbaren Code. Dieser Code kann verwendet werden, um Teile der Studie niedrigschwellig zu reproduzieren. Dies ist eine Möglichkeit selbst urheberrechtsgeschütztes Material in der Lehre einzusetzen, ohne, dass dieses unrechtmäßig in einer OER geteilt wird. Die Skripte können im Format eines Juypter Notebooks entweder heruntergeladen werden, um sie lokal auszuführen, oder über Clouddienste wie _Jupyter Hub_ oder _Colab_ ausgeführt werden. Bitte beachten Sie bei letzterer Variante das geltende Urheberrecht.
3. 📝 Pseudocode: Abschnitte, die mit einem Notziblock markiert werden, enthalten sogenannten [Pseudocode](https://de.wikipedia.org/wiki/Pseudocode). Dies ist eine technische Beschreibung eines Programms, die den Ablauf verdeutlichen soll, ohne Kenntnisse der verwendeten Progammiersprache vorauszusetzen. Für diese OER wird im Pseudocode auf Programmiersprache verzichtet, um diesen so niedrigschwellig wie möglich zu gestalten.

Die verschiedenen Formen können auch gemischt vorkommen (z. B. 📝📘).
